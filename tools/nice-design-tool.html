NICE Project Builder

Document a design project using Situation, Needs and Necessities, Inquiry, Create and Communicate, and Evaluate.
Use this builder while you work through a design project. Your entries are turned into a project document below. Needs are pass/fail requirements. Necessities are scored factors that help compare and improve a design.
